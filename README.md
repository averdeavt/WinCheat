# Cheats

## Windows

### Local User Win 11
Release builds (Windows 11 24H2)	“Choose your country” screen	Press Shift + F10	OOBE\BYPASSNRO	
Setup restarts, adds an “I don’t have Internet” path; choose “Continue with limited setup,” then create a local user.

Newer builds (26100/26200 (25H2) and beyond)	
Microsoft account Sign-in screen	Press Shift + F10	start ms-cxh:localonly	
A “Create a user for this PC” dialog opens; enter a local username and optional password.
